# Cross-paper Progression Documents
- Use JSON context for a summary of the papers and the code they use.
- Frame changes as **deeper understanding**, never "invalidation".
- Apply new methodologies operationally to earlier data (don't just juxtapose).
- Use published venue names (e.g., LION), not submission prefixes (e.g., evoapps).
- Make special emphasis on different treatments or conclusions gathered from the same dataset.
- Create a brief summary at the end that shows where the state of the art as of the latest paper published is now.


## Specific rules

- DON'T read data files, simply use the same commands that were used in the papers to load them.
- ALWAYS include charts in the output that show the improvement from one paper to the next (or to the last in the series)
